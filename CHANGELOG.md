# Changelog

## 1.0.0

First release.

- Gives the keyboard and mouse focus back to the virtual machine window (VMware Workstation by default; VirtualBox, Hyper-V or any window by setting) so the first click into the VM is not lost.
- Soft mode (default): returns the focus when no window covers the VM any more. Hover mode: also when the mouse moves and rests over the VM.
- Tray icon: pause, mode, Start with Windows, language (English, Russian), dry run, log.
- Reproducible build; release exe built by GitHub Actions with its SHA-256.
